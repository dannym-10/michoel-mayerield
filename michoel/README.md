# Michael Mayerfeld — Counsellor & Addiction Psychotherapist

Website for Michael Mayerfeld, built with React + TypeScript + Vite.

Live: [michaelmayerfeld.co.uk](https://michaelmayerfeld.co.uk)

## Pages

| Route | Component | Description |
|---|---|---|
| `/` | `Home` | Landing page |
| `/your-therapist` | `AboutMe` | About Michael |
| `/where-we-can-meet` | `WhereWeCanMeet` | Locations and online info |
| `/next-steps` | `NextSteps` | Contact form and booking |
| `/privacy-policy` | `PrivacyPolicy` | UK GDPR privacy policy |

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech

- React 18 + TypeScript
- Vite
- React Router v6
- SCSS modules
- Tailwind CSS (via `@tailwindcss/vite`)
